## 가져오기가 완료되지 않은 이유

확인 당시 대화에는 실행 작업 공간과 터미널 도구가 제공되지 않았습니다.
파일 다운로드는 다음 오류로 실패했습니다.

`download_file requires a ready execution workspace`

따라서 원본 코드 열람, 비밀정보·고객 데이터 검사, 앱 소스의 GitHub 업로드,
설치·테스트·빌드, 재배포는 수행하지 못했습니다.

## 다음 클라우드 작업에서 필요한 것

- 이 GitHub 저장소를 체크아웃할 수 있는 실행 작업 공간과 터미널
- 같은 계정에서 기존 프로젝트를 조회하고 배포할 수 있는 Sites 도구
- GitHub 및 Sites 원본 Git 저장소에 접근할 수 있는 네트워크와 권한

원본 Sites 저장소의 접속 정보와 단기 인증 정보는 Sites 도구로 필요할 때 발급받으세요.
토큰을 이 문서, Git 설정, 커밋, 채팅 출력, 로그에 기록하지 마세요.

## 진행 경로

1. `AGENTS.md`를 읽고 Sites에서 최신 프로젝트·버전·원본 소스 정보를 다시 조회합니다.
2. 원본 저장소를 별도 작업 디렉터리에 가져와 기존 앱의 구성과 개발 지침을 확인합니다.
3. 파일 내용과 전송 대상 전체를 검사해 비밀키, 실제 고객 정보, 운영 데이터, 로그, 백업을 제외합니다.
4. 검사된 코드만 GitHub에 반영합니다. 미검사 Git 이력을 통째로 복제하거나 미러링하지 않습니다.
5. 실제 코드에서 설치·실행·검증 명령을 확인하고, 합성 데이터로 테스트합니다.
6. 수정한 내용을 기존 Sites 원본 저장소에 반영하고, 그 저장소에 푸시된 정확한 커밋으로 빌드합니다.
7. 같은 프로젝트 ID로 버전을 저장하고 기존 사이트에 배포한 뒤 상태와 동작을 확인합니다.

GitHub에 푸시하는 것만으로 기존 Sites 사이트가 자동 배포되지는 않습니다.
현재 도구에서 GitHub 저장소로 원본 저장소 연결을 직접 교체하는 기능은 확인되지 않았습니다.
기존 Sites 원본 저장소를 유지하며 변경 사항을 반영하는 경로가 필요합니다.

운영 데이터를 초기화하거나 테스트 데이터로 교체하지 마세요.
